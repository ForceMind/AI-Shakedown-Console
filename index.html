macOS 安装、运行与更新教程
  1. 准备环境：先安装并登录所选 CLI。Codex 可按 OpenAI 官方 Codex CLI 教程安装，运行 codex 完成登录。启动器会优先使用系统 Node.js 18+，也会自动查找 Codex 桌面版自带的 Node。
  2. 下载脚本：点击“下载自检启动脚本”。下载文件名保持固定，不再显示网页版本号；重复下载若出现 (1)，可使用拖入终端的方法运行。
  3. 在终端运行：复制上面的完整命令，打开“终端”，按 ⌘ + V 粘贴，再按 Enter。请不要双击 .command；通过 bash 运行不需要修改文件执行权限。
  4. 找不到下载文件：在终端输入 bash 和一个空格，把刚下载的文件从“访达 → 下载”拖进终端，再按 Enter。此方法也适用于文件名带 (1) 或空格的情况。
  5. 允许访问下载目录：若 macOS 询问权限，只需允许“终端”访问“下载”文件夹；不需要开启完整磁盘访问。
  6. 连接与端口：脚本自检通过后会把桥接转入后台，当前 PWA 自动发现实际端口并连接，不会再弹出重复网页窗口。只有应用已关闭时，脚本才会尝试唤起已安装的 PWA；找不到 PWA 时才回退到默认浏览器。
  7. 停止或升级：网页点击“停止后台连接”即可停止；升级时直接运行新下载的脚本，旧桥接会自动退出并被新版替换。

启动器只做检查和连接，不会静默安装软件。缺少环境时会显示具体缺少项和安装入口。

专注聊天

连接排查

先用“检查连接”或本机工具的“检测连接”。失败时页面会自动打开设置并展开“请求检查器”；本机桥接成功转入后台后不需要保持终端开启。

数据与隐私
