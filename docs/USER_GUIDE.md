# 使用指南

本指南覆盖从第一次打开页面到长期使用的完整流程。遇到具体错误时，可直接前往 [故障排查](./TROUBLESHOOTING.md)。

## 第一次连接

### 使用远程 API

1. 在“服务商预设”中选择服务商。
2. 确认协议、Base URL、请求路径和模型。
3. 选择认证方式并填写 API Key。
4. 上游支持浏览器 CORS 时可直接连接；否则在 Cloudflare Pages 部署中开启“使用同域代理”。
5. 点击“检查连接”。页面先检查模型列表（配置了路径时），再发送一张 16×16 像素测试图片和极短回复请求。成功后设置自动收起，页面进入专注聊天。

测试图片用于确认当前“协议 + 地址 + 模型”是否真的接受多模态输入，因此会产生一次极小的模型请求。状态显示“连接正常 · 支持附件”时才出现附件按钮；显示“不支持附件”时仍可正常进行纯文本对话。Azure OpenAI 等没有标准模型列表路径的配置会跳过列表检查，但仍执行图片能力检查。

### 使用本机登录

在“服务商预设”中选择 Codex、Antigravity、Gemini CLI、Claude Code 或 OpenCode 的“本机登录”项，然后按页面提示下载启动器。完整操作见 [本机 AI 指南](./LOCAL_AI.md)。

## 发送与换行

| 环境 | 发送 | 换行 |
| --- | --- | --- |
| macOS | `⌘ + Enter` | 普通 `Enter` 或 `Shift + Enter` |
| Windows / Linux | `Ctrl + Enter` | 普通 `Enter` 或 `Shift + Enter` |
| 触摸设备 | 点击“发送” | 系统键盘的 Return/Enter |

页面会跟踪输入法的组合状态。中文、日文等输入法正在组词或选择候选词时，确认按键不会被误判成发送快捷键。

首次访问会自动显示一次环境帮助。之后可点击消息输入框右上角的 `?` 重新打开。

## 专注聊天与设置

页面有两种工作状态：

- **设置状态**：左侧显示连接、模型、生成参数、费用统计和请求检查器。
- **专注聊天**：连接成功后自动收起设置，只保留对话、智能体、System 状态、消息和发送操作。

点击页头的“设置 / 聊天”可以随时切换。连接或实际请求失败时，页面会自动打开设置并展开请求检查器。消息区会填满剩余高度，输入区在普通浏览器和 PWA 窄窗口中都固定在底部。

## 对话管理

- 点击“新对话”创建独立会话。
- 每个对话分别保存消息、System Prompt 和当前智能体。
- 首次成功回复后，对话名称会根据第一条用户消息生成。
- 1–4 个对话使用顶部页签；第 5 个开始自动切换为左侧列表。
- 一旦启用左侧列表，布局偏好会保存在当前浏览器，以后打开仍保持。
- 关闭当前对话不会删除其他对话。
- 工具栏可搜索当前对话、重命名并导出 Markdown 和 JSON。

## System 提示词

输入区上方只显示 System 的“未设置 / 已设置”状态，不再长期展开提示词原文。点击右侧“编辑”打开弹窗：

- “保存”把内容应用到当前对话，不影响其他对话。
- “取消”、右上角关闭或 `Esc` 会丢弃本次修改。
- 如果当前 System 来自智能体，手动改写并保存后会取消该智能体绑定，避免角色名与实际提示词不一致。
- 清空内容并保存后，当前对话恢复使用模型的默认行为。

## 消息编辑、复制与分支

每条消息下方的操作按钮在桌面端悬停或聚焦时显示，在触摸设备上始终显示：

- 用户消息：复制、选择、编辑并重新发送、从此处删除；请求失败时还会显示错误原因和“重试”。
- AI 消息：复制、选择、重新生成、继续生成、从此处删除。
- 编辑最后一轮会替换该轮；编辑已有后续用户消息的旧内容会自动创建新对话分支，原对话保持不变。
- 选择任意消息后可全选、复制为 Markdown、导出选中内容或删除；删除操作提供撤销入口。

AI 回复中的每个代码块有独立“复制代码”按钮。所有复制和导出都使用原始 Markdown 文本，不会带入界面按钮或 HTML。

## 附件与多模态

附件按钮只在当前配置通过真实图片能力检查后显示。修改协议、Base URL、请求路径或模型后，页面会立即重新匹配该配置的能力记录；未知或不支持时隐藏按钮，重新点击“检查连接”即可验证。

支持的文件：

| 类型 | 处理方式 | 单文件限制 |
| --- | --- | --- |
| PNG / JPEG / WebP / GIF | 作为图片输入发送给模型 | 5 MiB |
| 文本、Markdown、代码、JSON、CSV、YAML 等 | 浏览器本地读取并以带文件名的文本段发送 | 1 MiB |
| 含文字层的 PDF | 使用本地 PDF.js 提取文字，不上传原 PDF 二进制 | 10 MiB、100 页 |

每条消息最多 6 个附件，原始大小合计不超过 12 MiB。提取后的文本最多 500,000 字；扫描版 PDF 不包含文字层，当前版本不做 OCR。可使用附件按钮选择文件，也可把文件拖入输入区域；支持的浏览器还可以直接粘贴剪贴板图片。

图片会分别映射为 OpenAI `image_url`、Anthropic base64 image block 或 Gemini `inlineData`。文本与 PDF 提取结果会附在消息文字后。请求检查器会隐藏长 base64 数据，但文本附件内容仍属于请求的一部分，发送前应确认文件适合交给当前模型服务商。

## 智能体库

输入区上方的“智能体库”分为两类：

- **内置智能体**：268 个中文专家角色，可按部门筛选、搜索、预览并应用。
- **自定义智能体**：可新建、编辑、保存和删除自己的 System 角色；编辑框自动按 GitHub Flavored Markdown 生成安全实时预览。

应用智能体会替换当前对话的 System Prompt，并只影响当前对话。Markdown 预览只改变显示方式，保存和发送给模型的仍是原始 Markdown 文本。旧版本保存在 `prompts.v1` 的提示词会自动显示在自定义智能体区。

## 配置库

配置库保存连接所需的完整参数，包括服务商、协议、地址、路径、认证、API Key、模型、生成参数和费用设置。

- “保存”会创建或覆盖当前命名配置。
- “加载”把已选配置应用到页面。
- “新建”退出当前配置选择，适合另存一份。
- “删除”只删除命名配置，不会删除对话。

配置库保存在浏览器本地，不会跨浏览器或设备同步。

## 导入本地对话

点击对话区域的“导入记录”，可选择一个或多个文件，也可在支持目录选择的浏览器中选择整个目录。

常见目录：

| 来源 | 常见位置 |
| --- | --- |
| Codex | `~/.codex/sessions/` |
| Gemini CLI | `~/.gemini/tmp/*/chats/` |
| Claude Code | `~/.claude/projects/` |

页面支持 Codex、Gemini CLI、Claude Code 记录，以及常见 JSON/JSONL 消息结构。每个成功导入的记录会成为独立对话，可使用当前模型继续。

导入限制：单文件不超过 20 MiB，总计不超过 60 MiB，最多 200 个文件。页面会跳过明显的凭据或敏感配置文件名。

## 模型与参数

- “读取”会从服务端获取模型列表并按能力、参数规模和版本排序。
- “自定义模型…”允许输入列表中没有的模型 ID。
- OpenAI Compatible 与本机 Codex 支持 `reasoning_effort`；“自动”表示不发送该字段。
- Temperature、Top P、Top K 和最大输出 Token 仅在对应协议支持时生效。
- 输入/输出单价由用户手动填写；只有 API 返回 usage 时才会累计 Token 和费用。
- 费用上限达到后页面会锁定发送，重置统计后恢复。

## 请求检查器

请求检查器位于设置底部，可查看：

- 脱敏后的 URL 和请求头；
- 实际请求体；
- 响应体；
- 最近的 SSE 流式事件；
- HTTP 状态和耗时。

API Key、Authorization 和敏感查询参数会在显示时脱敏。复制检查信息前仍应确认内容中没有业务敏感数据。

## 安装 PWA

### Chrome / Edge

使用 HTTPS 打开线上站点，在设置中点击“安装为桌面应用”；如果没有显示按钮，可使用地址栏或浏览器菜单中的安装入口。

macOS 上由 Edge 安装的 PWA 是一个独立的原生 App Shim。若第三方中文输入法可以输入拼音但不显示候选窗，这与网页内候选词确认被快捷键打断不是同一问题。重装 Edge PWA 只能临时刷新输入上下文，浏览器更新后可能复发。

需要长期稳定使用第三方中文输入法时，请改用下方 Safari Web App；普通 Edge 标签页也不会依赖 PWA App Shim。完整原理和应急步骤见 [Edge PWA 输入拼音但没有候选窗](./TROUBLESHOOTING.md#edge-pwa-输入拼音但没有候选窗)。

### Safari / iPhone / iPad

- macOS Safari：打开本站，使用“文件 → 添加到程序坞”。这是 macOS 第三方中文输入法的推荐安装方式，不依赖 Edge 的更新和 App Shim 生命周期。
- iPhone/iPad：使用分享菜单中的“添加到主屏幕”。

### 离线范围

离线时可以打开应用外壳，并查看当前浏览器已保存的配置、智能体和对话。远程 API 仍需要网络，本机 AI 仍需要同一台电脑上的桥接进程。

内容更新安装完成后，页面会显示“立即刷新”。确认后切换到新缓存，不会清空现有本地数据。同一个公开版本的候选修订也会使用独立缓存修订号，避免 PWA 继续使用旧脚本。

## 浏览器数据

下列内容保存在当前站点的 `localStorage`：

- 当前连接设置与 API Key；
- 命名配置；
- 自定义智能体；
- 对话、消息、System Prompt 和激活项；
- 对话左侧列表偏好；
- 首次帮助是否已显示；
- Edge PWA 输入法长期方案是否已提示。
- 每个“协议 + 地址 + 模型”最近一次多模态能力检查结果。

附件二进制或提取文字保存在当前站点的 `IndexedDB`，对话消息只保存附件元数据与引用。附件草稿在刷新后继续保留；删除消息、关闭对话或清除本地数据后，页面会清理不再引用的附件。

本机桥接的随机配对令牌只保存在当前标签页的 `sessionStorage`。

在共享设备上使用后，请点击设置中的“清除全部本地数据”。这会清除浏览器内的项目数据，但不会删除本机 CLI 登录或磁盘上的原始对话记录。

## 自定义服务

1. 选择“自定义 / 自建站”。
2. 选择服务端实际支持的协议。
3. 填写 Base URL、请求路径、模型和认证方式。
4. 如需额外请求头或参数，在“高级连接设置”中填写 JSON 对象。
5. 上游没有开放 CORS 时，仅在受控的 Cloudflare Pages 部署中开启同域代理。

请求路径支持 `{model}`；Gemini 路径还支持 `{action}`，页面会根据流式开关替换为 `generateContent` 或 `streamGenerateContent?alt=sse`。
