## 当前迭代

用户可操作：侧栏新建/切换会话与智能体库；顶部模型名称或设置进入原有连接配置；主区聊天与附件；右上角菜单搜索、重命名、导出、清空；输入框“提示词”编辑 System，保留角色取消入口。

- 桌面默认 272px 会话侧栏，中等宽度收窄到 248px；设置展开为 344px。侧栏支持收起。
- 手机默认关闭抽屉，通过左上角图标打开；选择或新建对话后关闭。隐藏侧栏退出键盘与辅助技术访问范围。
- 白色主区、浅灰用户气泡、模型正文、居中阅读宽度和圆角输入框；保留系统安全区、触摸字号、短横屏布局。
- 网页版本 v32；Android 原生壳与已分发 APK 保持 v31。网页未部署，APK 当前仍加载已有线上站点。
- 不更换技术栈，不添加依赖，不迁移聊天或附件存储，不调整连接、代理或本机桥接协议。

涉及页面文件 `index.html`、`style.css` 和 `script.js`，版本/缓存文件、相关指南与非浏览器验证。后续精细视觉调整、真实浏览器/设备验收、合并和部署另行开展。
